# Calculator

A simple browser-based calculator built with HTML, CSS, and JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Percentage and decimal input
- Clear the display with **AC**
- Delete the last character with **DEL**

## Run locally

Open `index.html` in a web browser. No installation or build step is required.

## Project files

- `index.html` — calculator layout and buttons
- `style.css` — page styling
- `script.js` — calculator interaction and calculations
